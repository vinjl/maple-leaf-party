# The Maple Leaf — Citizen Issues Platform (MCIP)

**Version:** 0.1  
**Status:** Framework draft  
**Depends on:** `05-open-state-architecture.md`, `09-gov-as-open-source.md`

---

## 1. Thesis

Open government without a **write path** is a museum.  
MCIP is the national **bug tracker**: issues, suggestions, fraud docket, maintainer SLAs, signature ladder to referendum.

> **Government is a public repository. File a bug. Maintainers don’t ghost you.**

---

## 2. Citizen actions

| Action | Detail |
|--------|--------|
| Bug | Broken process, SLA miss, missing Trace, bad service |
| Suggestion | PR-style fix against `process_id` / statute |
| Fraud / waste | Evidence upload; public by default |
| Second / upvote | **Verified citizens only** — one person one weight |
| Track | Open → triaged → assigned → fixed/declined **publicly** |

---

## 3. Government duties

| Duty | Rule |
|------|------|
| Citizen Issues Authority | Under Open State / Chief Open State Officer |
| Domain review teams | Tax, benefits, procurement, etc. + **Fraud Cell** |
| Triage SLA | Days, not months (published) |
| CODEOWNERS | Named official per process |
| AI State | Cluster dupes, draft fixes; **human decides** |
| Bounties | Pay citizens when verified waste/fraud **cuts real tax spend** (see §3b) |

---

## 3b. Public waste & fraud bounty (citizen rewards)

Encourage the whole country to fix the machine — not wait four years for a do-nothing term.

| Rule | Detail |
|------|--------|
| **Who** | Verified Canadian citizens |
| **What** | Waste, fraud, ghost programs, sole-source abuse, failed spend — tied to Trace / ledger where possible |
| **Pay when** | Finding is **verified** and produces a **measurable reduction** in tax-dollar use (clawback, cancel, redesign, stop-pay) |
| **Scale** | Reward **scales with verified fiscal impact** (published tiers or capped % of recovered/saved) |
| **Protect** | Lawful whistleblowing path; penalties for malicious false claims |
| **Publish** | Paid bounties and savings on a public scoreboard |

Software/security bounties (ledger, election tooling) remain under `09` SECURITY rules; this section is the **fiscal impact** path for ordinary citizens.

---

## 4. Fraud docket

- Public by default  
- Temporary seal only for active criminal process or serious doxxing risk  
- Confirmed → ledger Trace, clawback, prosecution  
- Malicious false claims → misuse penalties  
- No burying because a minister is embarrassed  

---

## 5. Signature ladder → referendum

| Level | Escalation |
|-------|------------|
| Low N | Must stay open; manager reply |
| Mid N | Minister/committee on calendar |
| High N + legal screen | **Referendum / ballot initiative** if constitutionally eligible |
| Severe fraud cluster | AG + police fast-track (not popularity contest) |

**Referendum rules:** citizens only; single subject; costed estimate; cannot hashtag-repeal Charter; anti-bot; binding for defined ordinary-law classes, advisory/complex otherwise unless Parliament ratifies.
