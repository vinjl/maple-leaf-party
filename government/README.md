# Open Government of Canada — Maple Leaf model

This folder is a **public prototype of government**: how a logic-based state would be organized, operated, and audited.

It is **not** the legal Government of Canada. It is a design you can read, fork, and improve — the way open source works.

The **website** (`/website`) is the public front door.  
This tree is the **building**.

## Citizens first test

Every file in this tree should answer:

> Does this make life for **Canadian citizens** safer, smarter, stronger, and richer?

If not, it does not belong.
